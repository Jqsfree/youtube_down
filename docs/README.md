# 文档索引

本目录区分**当前使用说明**、**开发规范**与**历史实施证据**。首次使用从仓库根目录 [README](../README.md) 开始。

| 想解决的问题 | 权威入口 | 维护规则 |
| --- | --- | --- |
| 如何安装、输入、下载和续传？ | [使用手册](usage.md) | 按已发布版本与 main 差异注明状态 |
| 下载失败、Cookie 失效或更新失败？ | [故障排查](troubleshooting.md) | 先识别症状和错误类别，再给验证手段 |
| 如何改代码并运行测试？ | [开发与验收](development.md) | 给出可运行命令及其验证边界 |
| 软件如何分层、为何不重构？ | [架构说明](architecture.md) | 现状、职责、数据流、策略差异分开陈述 |
| 如何构建、更新依赖和发布？ | [构建与发布](../BUILD.md) | 以工作流和脚本为准 |
| 变更了什么？ | [Changelog](../CHANGELOG.md) | `Unreleased` 不等于已发布安装包 |
| Agent 可以改什么、怎样验收？ | [AGENTS.md](../AGENTS.md) | 仅保留可执行约束，避免复制多份 |
| 如何撰写文档？ | [文档规范](documentation-style.md) | 事实、范围、证据、链接和状态一致 |

## 阅读顺序

用户：根目录 README → 使用手册 → 故障排查。

贡献者/Agent：根目录 README → 开发与验收 → 架构说明 → AGENTS.md / BUILD.md；仅需追溯设计决策时阅读历史记录。

新建文档前先判断是否能更新现有权威页。不要在多个 Markdown 文件中维护相同 CLI 默认值、安装包版本或测试结果。
